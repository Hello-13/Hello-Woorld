Fretboard Companion

A chromatic tuner, a chord of the day you can strum, a metronome and a practice-streak tracker in one card. Add one script tag and it fits into any dashboard.

Add it to your dashboard

One file, no build step and no dependencies. It renders inside Shadow DOM, so your dashboard’s CSS can’t break it and its CSS can’t leak out.

HTML
<!-- once, anywhere on the page -->
<script src="fretboard-companion.js" defer></script>

<!-- wherever the card should go -->
<fretboard-companion weekly-goal="150"></fretboard-companion>
Sync practice to your backend
const fc = document.querySelector('fretboard-companion');

fc.addEventListener('practice-logged', (e) => {
  // { date: '2026-10-12', minutes: 25, totalForDay, streak, weekMinutes }
  fetch('/api/practice', { method: 'POST', body: JSON.stringify(e.detail) });
});

// Restore history saved elsewhere
fc.setPracticeLog({ '2026-10-11': 30, '2026-10-12': 25 });

Live events

The widget fires DOM events as you use it. These are the ones your dashboard can listen for.

  • Strum a chord, start the metronome or log practice. Events show up here.

Attributes

All optional.

AttributeDefaultWhat it does
themeautolight, dark, or auto. Auto follows data-theme, a .dark class on <html>, or the OS setting.
weekly-goal150Practice minutes per week for the goal bar.
a4440Reference pitch in Hz for the tuner and tones (400–480).
bpm96Starting tempo when nothing is saved yet.
tabtunerOpening tab: tuner, chords, metronome or practice.
storage-keyfretboard-companionlocalStorage key, so two cards can keep separate logs.
sample-dataoffShows example history until the first real session is logged.
no-fontsoffSkips loading Google Fonts and uses your dashboard’s fonts.
